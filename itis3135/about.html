About ITIS 3135

This page was created as part of the ITIS 3135 - Front-End Web Application Development course at UNC Charlotte with Professor D.I. von Briesen. More information about this course can be found on the ITIS 3135 course website .

This course gives students hands-on experience in front-end web application development by creating multiple websites using different tools and coding techniques. Throughout the course, we will learn how to design, develop, test, and publish websites.

Tools Used in This Course

  • VS Code
  • Emmet within VS Code
  • FileZilla
  • Git via GitHub Desktop and GitHub.com
  • Various browser tools
  • The Accumulus Validator

Websites and Projects

Throughout the course, we will create several websites and projects, including:

  • A personal homepage
  • A course site for ITIS 3135
  • A design firm website
  • A "Crappy" webpage
  • A whimsical product company website
  • A student, colleague, or peer management tool
  • A client project website
