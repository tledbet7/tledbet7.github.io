Documentation

Welcome to the Thriving Ladybug Web Development Guide! This documentation explains the basic steps for creating a webpage using HTML, CSS, and Visual Studio Code. Every website starts with small steps that lead to big possibilities.

Getting Started HTML Basics Adding Content CSS Styling Previewing Your Webpage

Getting Started

Before creating a webpage, you need a code editor and a folder to store your project files.

  1. Open Visual Studio Code.
  2. Create a new folder for your website.
  3. Open that folder in VS Code.
  4. Create a file named index.html.
  5. Create another file named style.css.

HTML Basics

HTML provides the structure of a webpage. Every HTML document starts with a basic structure that includes a head and body. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Webpage</title>
</head>
<body>
    <h1>Hello, World!</h1>
</body>
</html>

Adding Content

You can add headings, paragraphs, images, and links to make your webpage more interesting. 

<h1>Welcome to My Website</h1>
<p>This is my first webpage.</p>
<a href="about.html">About Me</a>

Headings organize your content, paragraphs provide information, and links help visitors navigate between pages.

CSS Styling

CSS controls the appearance of your webpage. You can change colors, fonts, spacing, and other design elements. 

body {
    background-color: lavender;
    font-family: Arial, sans-serif;
    color: #51465d;
}

h1 {
    text-align: center;
}

To connect your CSS file to your HTML, add this line inside the head section: 

<link rel="stylesheet" href="style.css">

Previewing Your Webpage

Once your HTML and CSS files are ready, you can preview your webpage in a browser.

  1. Save your HTML and CSS files.
  2. Open your project in VS Code.
  3. Right-click your index.html file.
  4. Select Open with Live Server.
  5. Check your webpage in the browser.

Continue practicing by adding more content and experimenting with different designs. Remember, small steps lead to big possibilities!
